# 🌿 Шаблонизатор гербариев А4

Интерактивный редактор гербарных карточек формата А4 с AI-ассистентом (DeepSeek / Yandex GPT), интерактивным кадрированием фото и сохранением проектов.

## 🚀 Быстрый старт

### 1. Бэкенд (прокси для AI)

```bash
cd backend
npm install
npm start
```

По умолчанию запускается на `http://localhost:3000`.

### 2. Фронтенд

Открой `frontend/index.html` в браузере (Live Server в VS Code, или просто двойной клик).

> **Важно:** фронт и бэкенд должны быть на одном домене, либо бэкенд должен разрешать CORS. В `server.js` уже включён `cors()`.

## 🌐 Деплой

### Вариант A: Раздельно (рекомендуется)

| Что | Куда | Как |
|-----|------|-----|
| **Фронтенд** | GitHub Pages | Залей `frontend/` в репозиторий, включи Pages в настройках |
| **Бэкенд** | Render / Railway / Fly.io | Залей `backend/`, добавь переменную окружения `PORT=3000` |

В настройках AI в приложении укажи URL задеплоенного бэкенда.

### Вариант B: Всё вместе (проще)

Залей весь репозиторий на **Vercel** или **Netlify** — они поддерживают serverless-функции. Перенеси `backend/server.js` в `api/ai.js` по их документации.

## 🔑 Получение API-ключей

### DeepSeek
1. Регистрация: [platform.deepseek.com](https://platform.deepseek.com)
2. Пополни баланс (минимум $1)
3. Создай API-ключ в разделе "API Keys"

### Yandex GPT
1. [console.cloud.yandex.ru](https://console.cloud.yandex.ru) → создай платёжный аккаунт
2. Перейди в **YandexGPT** → **Сервисные аккаунты** → создай API-ключ
3. Или используй IAM-токен (но API-ключ проще)

---

## ⚙️ Как это работает

1. Пользователь вводит русское название растения
2. Приложение отправляет запрос на **твой бэкенд** (не напрямую в API!)
3. Бэкенд подставляет секретный ключ и ходит в DeepSeek / Yandex
4. Ответ возвращается на фронт — ты проверяешь и применяешь

Так API-ключ **никогда не попадает в браузер** пользователя, а CORS-проблема решается прокси.
